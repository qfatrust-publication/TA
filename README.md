# Rihla TA: শুরু থেকে শেষ গাইড

সবকিছু ফ্রি, কার্ড লাগবে না। শুধু একটি Google অ্যাকাউন্ট ও একটি GitHub অ্যাকাউন্ট লাগবে। প্রতিটি ধাপ একটার পর একটা করুন, কোনো ধাপ বাদ দেবেন না।

## ক. অ্যাপ অনলাইনে তোলা (GitHub)

1. github.com এ গিয়ে অ্যাকাউন্ট খুলুন (Sign up)।
2. ওপরে ডানে **+** → **New repository**। নাম দিন `teachers-support`, **Public** রাখুন, **Create repository** চাপুন।
3. পরের পাতায় **uploading an existing file** লিংকে চাপুন। `index.html` ফাইলটি টেনে এনে ছাড়ুন, নিচে **Commit changes** চাপুন।
4. রিপোর **Settings** → বাঁয়ে **Pages** → Branch: **main**, ফোল্ডার **/ (root)** → **Save**।
5. ১–২ মিনিট পর ওই পাতার ওপরে আপনার সাইটের লিংক আসবে: `https://আপনার-ইউজারনেম.github.io/teachers-support/`। লিংকটি কপি করে রাখুন।

## খ. ডেটাবেজ ও লগইন সিস্টেম (Firebase)

6. console.firebase.google.com এ Google অ্যাকাউন্ট দিয়ে ঢুকুন → **Create a project** → যেকোনো নাম → Google Analytics বন্ধ রেখে **Create project**।
7. বাঁয়ে **Build → Authentication** → **Get started** → **Email/Password** → চালু (Enable) করে **Save**।
8. বাঁয়ে **Build → Firestore Database** → **Create database** → লোকেশন `asia-south1` (মুম্বাই, বাংলাদেশের সবচেয়ে কাছে) → **Production mode** → **Enable**।
9. Firestore এর **Rules** ট্যাবে সব লেখা মুছে নিচের রুলস পেস্ট করে **Publish** চাপুন:

```
rules_version = '2';
service cloud.firestore {
  match /databases/{db}/documents {
    function isAdmin() {
      return request.auth != null &&
        exists(/databases/$(db)/documents/admins/$(request.auth.uid));
    }
    match /items/{id} {
      allow read: if request.auth != null;
      allow write: if isAdmin();
    }
    match /users/{uid} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
      allow read: if isAdmin();
    }
    match /admins/{uid} {
      allow read: if request.auth != null && request.auth.uid == uid;
    }
  }
}
```

10. ওপরে বাঁয়ে ⚙ (Project settings) → **General** → নিচে **Your apps** → `</>` (Web) চাপুন → একটি নাম দিন → **Register app**। যে `firebaseConfig` দেখাবে, তার চারটি মান (apiKey, authDomain, projectId, appId) কপি করুন।
11. GitHub এ আপনার রিপোতে `index.html` খুলুন → ✎ (Edit) → `CFG` লাইনে `YOUR_API_KEY`, `YOUR_PROJECT`, `YOUR_APP_ID` এর জায়গায় আপনার মানগুলো বসান (কোটেশন চিহ্ন রেখে) → **Commit changes**। এই কোড গোপন নয়, নিরাপত্তা আসে ধাপ ৯ এর রুলস থেকে।
12. Firebase এ **Authentication → Settings → Authorized domains → Add domain** → লিখুন `আপনার-ইউজারনেম.github.io` (শুধু ডোমেইন, পুরো লিংক নয়) → **Add**।

## গ. নিজেকে অ্যাডমিন বানানো

13. আপনার সাইটের লিংকের শেষে `#/register` যোগ করে খুলুন (যেমন `.../teachers-support/#/register`)। ফর্ম পূরণ করে নিজে একবার নিবন্ধন করুন।
14. Firebase এ **Authentication → Users** এ আপনার ইমেইলের পাশে **User UID** কপি করুন।
15. **Firestore Database → Start collection** → Collection ID লিখুন `admins` → Document ID তে UID পেস্ট করুন → Field: `ok`, Type: `boolean`, Value: `true` → **Save**।
16. অ্যাপে **বের হন** চাপুন, তারপর `.../teachers-support/#/admin` লিংকে গিয়ে একই ইমেইল-পাসওয়ার্ড দিয়ে ঢুকুন। এটাই আপনার অ্যাডমিন লিংক। ওপরে "সম্পাদনা মোড" ও "শিক্ষক তালিকা" দেখলে সফল।

## ঘ. কনটেন্ট তোলা

**হাতে হাতে:** সব বই পাতায় **＋ নতুন বই** → বই খুলে **＋ নতুন অধ্যায় (ইউনিট)** → লেসন → তাদরিব। তাদরিবে ৪টি সেকশন আসে (লক্ষ্য-উদ্দেশ্য, পড়ানোর কৌশল, উত্তর, সাধারণ ভুল)। সম্পাদনা ফর্মে সেকশন যোগ, নাম বদল বা মোছা যায়। ✎ দিয়ে সম্পাদনা, ✕ দিয়ে মোছা।

**একসাথে অনেক (JSON ইমপোর্ট):** যেকোনো পাতায় **JSON ইমপোর্ট** চাপলে ওই পাতার ভেতরে নতুন আইটেম যোগ হয়। যেমন বইয়ের পাতায় ইমপোর্ট করলে ইউনিট, ইউনিটের পাতায় লেসন, লেসনের পাতায় তাদরিব। ভেতরের স্তরগুলো `c` এর মধ্যে থাকে। উদাহরণ (ইউনিটের পাতায় ইমপোর্টের জন্য):

```
[
  {"t": "لَيْسَ: লেসন ২", "c": [
    {"t": "১. انظر واستمع وأعد", "pg": "পৃ. ৩",
     "s": [
       {"t": "লক্ষ্য-উদ্দেশ্য", "b": "নতুন ১২টি শব্দ চেনা"},
       {"t": "পড়ানোর কৌশল", "b": "ছবি দেখিয়ে শব্দ বলুন..."},
       {"t": "উত্তর", "b": "প্রযোজ্য নয়"}
     ]}
  ]}
]
```

`t` শিরোনাম (বাধ্যতামূলক), `pg` বইয়ের পৃষ্ঠা, `s` সেকশনের তালিকা, `c` ভেতরের স্তর। অন্য Claude চ্যাটে কনটেন্ট বানাতে এই নির্দেশ দিন:

> উপরের ইউনিটের প্রতিটি লেসন ও তাদরিবের গাইডলাইন লিখে শুধু এই JSON ফরম্যাটে দাও (কোনো ব্যাখ্যা ছাড়া): লেসনের তালিকা, প্রতিটির `c` এ তাদরিব; প্রতিটি তাদরিবে `t`, `pg` ও `s` (লক্ষ্য-উদ্দেশ্য, পড়ানোর কৌশল, উত্তর, সাধারণ ভুল)।

**একই ফাইল বারবার দিলে:** একই জায়গায় একই শিরোনামের আইটেম থাকলে নতুন করে যোগ হয় না, বরং সর্বশেষ ইমপোর্টের লেখায় আপডেট হয়। ইমপোর্টের আগে অ্যাপ জানাবে কতটি নতুন যোগ ও কতটি আপডেট হবে। মনে রাখবেন: (১) শিরোনাম বদলালে সেটি নতুন আইটেম গণ্য হবে; (২) `s` (সেকশন) দিলে ওই তাদরিবের সব সেকশন বদলে যায়, তাই হাতে আলাদা সম্পাদনা করা থাকলে তা মুছে যাবে, আর `s` না দিলে সেকশন যেমন আছে তেমন থাকে; (৩) ইমপোর্ট কখনো কিছু মোছে না।

Claude এর দেওয়া JSON কপি করে ইমপোর্ট ঘরে পেস্ট করুন (অথবা `.json` ফাইল বেছে নিন)। ভুল দেখালে সেই লেখাটি Claude কে দিয়ে বলুন "JSON ঠিক করে দাও"।

**ব্যাকআপ:** ওপরের **ব্যাকআপ ডাউনলোড** বোতামে চাপলে পুরো কনটেন্ট (হাতে যোগ করা ও ইমপোর্ট করা, সবই) একটি JSON ফাইলে নামে। সপ্তাহে একবার, আর বড় কাজ বা বড় মোছার আগে, ফাইলটি নামিয়ে Google Drive এ রাখুন। কখনো সব হারালে সব বই পাতায় **JSON ইমপোর্ট** এ এই ফাইল দিলেই সব ফিরে আসবে (একই শিরোনামের আইটেম ব্যাকআপের অবস্থায় ফিরবে, ব্যাকআপের পরে যোগ করা নতুন আইটেম থেকে যাবে)। ✕ বোতামে একবার নিশ্চিত করলেই ভেতরের সবসহ মুছে যায়, ফেরত আনার উপায় নেই।

## ঙ. সার্চ ও নেভিগেশন

- ওপরের সার্চ বক্সে শিরোনামের **শুরুর অংশ** লিখে Enter চাপলে মিলে যাওয়া আইটেম ও তার অবস্থান দেখায়। ভেতরের মাঝের শব্দ দিয়ে খোঁজা যায় না।
- তাই তাদরিবের শিরোনাম এভাবে দিন: `১. انظر واستمع وأعد`। তাহলে "انظر" বা "১." লিখে খুঁজে পাবেন।
- তাদরিবের পাতার নিচে **আগের / পরের** বোতামে একই লেসনের অন্য তাদরিবে যাওয়া যায়।

## চ. পরে অ্যাপ আপডেট

GitHub এ `index.html` খুলে ✎ → বদলান → **Commit changes**। ১ মিনিট পর পেজ রিফ্রেশ করুন। নতুন ফাইল আসলে (যেমন Claude এর দেওয়া নতুন সংস্করণ) ফাইলের পাশের `⋯` বা **Add file → Upload files** দিয়ে একই নামে আপলোড করলে আগেরটি বদলে যায়। আপডেটের আগে `index.html` এর কপি সেভ করে রাখুন, আর `CFG` এর মান আবার বসাতে ভুলবেন না।

## ছ. সমস্যা হলে

| সমস্যা | সমাধান |
|---|---|
| সাদা পাতা | ধাপ ১১ এর `CFG` মান ঠিক আছে কিনা দেখুন, ব্রাউজার রিফ্রেশ করুন |
| `unauthorized-domain` | ধাপ ১২ করুন |
| "এই কাজের অনুমতি নেই" | ধাপ ৯ এর রুলস ও ধাপ ১৫ এর `admins` ডকুমেন্ট ঠিক আছে কিনা দেখুন |
| অ্যাডমিন লিংকে "অ্যাডমিন নয়" | ধাপ ১৫ এ UID ভুল বসেছে |
| পরিবর্তন দেখা যাচ্ছে না | Ctrl+Shift+R চাপুন, মোবাইলে ক্যাশ মুছুন |

ফ্রি সীমা: প্রতিদিন প্রায় ৫০,০০০ রিড ও ২০,০০০ রাইট। অ্যাপ শুধু খোলা স্তরের ডেটা পড়ে, তাই শত শত শিক্ষকের জন্যও সাধারণত যথেষ্ট। Firebase এর Usage ট্যাবে মাঝেমধ্যে দেখে নেবেন।

## জ. মোবাইলে অ্যাপ হিসেবে ইন্সটল

অ্যাপ ইন্সটল হতে `index.html` এর পাশাপাশি আরও চারটি ফাইল একই ফোল্ডারে (একই রিপোতে) থাকতে হবে: `manifest.webmanifest`, `sw.js`, `icon-192.png`, `icon-512.png`।

1. GitHub এ রিপো খুলুন → **Add file → Upload files** → পাঁচটি ফাইল একসাথে টেনে এনে ছাড়ুন (পুরোনো `index.html` নিজে থেকে বদলে যাবে) → **Commit changes**।
2. ১–২ মিনিট অপেক্ষা করুন। মোবাইলের Chrome এ সাইটটি খুলে পাতা একবার রিফ্রেশ করুন।
3. ওপরের মেনুতে **ইন্সটল করুন** বোতাম এলে সেটি চাপুন। না এলে Chrome এর তিন ডট (⋮) → **Install app** (অথবা **Add to Home screen**) চাপুন।
4. আগে ইন্সটল না হওয়ার কারণ ছিল এই ফাইলগুলো না থাকা। এখনো না হলে Chrome এর সেটিংসে সাইটের ক্যাশ মুছে আবার চেষ্টা করুন।
